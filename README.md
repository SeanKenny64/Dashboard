Personal Dashboard

A lightweight personal command centre built around TaskWarrior, with the aim of bringing tasks, projects, information and AI assistance into one place.

The dashboard currently provides:

TaskWarrior integration — surfacing useful tasks through the Arena rather than overwhelming the user with everything.
Information feeds — including curated RSS/news sources.
Project and system information — a central place to see what's happening.
AI integration — an evolving foundation for connecting the dashboard to AI agents and tools.

The longer-term goal is to turn the dashboard into a personal AI-assisted operating environment: something that can understand the current state of work, help decide what matters, and eventually take actions through connected tools.

Built primarily with Python, JavaScript, HTML/CSS and TaskWarrior.
